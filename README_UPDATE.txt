Dota Market Bot — сборка с Telegram и автообновлением

TELEGRAM
1. Открой «Настройки».
2. Включи «Использовать Telegram-бота».
3. Вставь токен BotFather и свой chat_id.
4. Нажми «Сохранить настройки».
5. Токен и chat_id сохраняются в data/config.json. Поле токена скрыто по умолчанию.
6. Telegram запускается отдельно от сканера и автопокупки.

АВТООБНОВЛЕНИЕ
Репозиторий: https://github.com/Diroun/DotaBotmarket
Текущая версия в updater.py: CURRENT_VERSION = "1.0.0".

Чтобы опубликовать новую версию:
1. Отправь исходный код проекта в GitHub-репозиторий.
2. Измени CURRENT_VERSION в updater.py на новый номер (например, 1.0.1).
3. Создай ZIP для релиза. В корне ZIP должны лежать main.py, gui.py,
   updater.py и остальные файлы программы. Допускается одна общая папка
   верхнего уровня, внутри которой находится main.py.
4. В GitHub открой Releases → Draft a new release.
5. Создай тег вида v1.0.1 и прикрепи ZIP-архив как asset релиза.
6. Опубликуй релиз. При следующем запуске программы пользователи увидят
   предложение обновиться. Вкладка «Настройки» → «Проверить обновления»
   позволяет проверить вручную.

Обновление скачивается только из GitHub Releases. Перед заменой файлов
создаётся резервная копия файлов приложения. Папка data/ не заменяется:
в ней остаются API-ключ, Telegram-токен, настройки, база данных и история.
Автоустановка в этой версии рассчитана на Windows и запуск через Python.

ВАЖНО О БЕЗОПАСНОСТИ
Не публикуй data/config.json с настоящими ключами или токенами.
В GitHub следует загрузить только конфигурационный шаблон с пустыми
значениями api_key, telegram_token и telegram_chat_id.
Если действующие токены когда-либо попадали в публичный архив, отзови их
через соответствующие сервисы и выпусти новые.
